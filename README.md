# 烟花连通 Fireworks Connect

![Fireworks Connect preview](./assets/cover.svg)

一款专为移动端与桌面浏览器打造的节庆风管道连通益智小游戏。玩家通过旋转棋盘中的管道，将左侧火源与右侧火箭精确连通，在限定时间内点火结算、引爆绚丽烟花，并冲击更高关卡与历史最高分！

## ✨ 核心特性

- **纯原生前端实现**：零外部框架与打包依赖，Vanilla HTML5 + CSS3 + ES6，秒开即玩。
- **严谨的数学可解性算法**：关卡完全由算法动态生成，100% 保证必定有解，包含分支（Tee）、交叉（Cross）与**立体过桥（Bridge）**双线跨越机制。
- **10 级梯度进阶关卡**：从第 1 关的 3×3 基础练习到第 10 关的 10×10 巨型迷宫，倒计时与通关门槛逐步递增。
- **国风节庆 3D 拟真视觉**：温暖明朗的节庆配色，立体圆柱管道阴影、霓虹光波动态追踪、纯 DOM/CSS 硬件加速烟花粒子特效。
- **底层 Web Audio 合成音效**：完全脱离外部 MP3/WAV 资源，通过浏览器底层音频振荡器实时合成旋转、点火、爆炸与节庆背景音乐（BGM），并支持音效与音乐**独立静音开关**。
- **全平台自适应**：深度针对移动端触摸屏优化，防误触放大，支持全屏视口自适应与本地最高分记录（`localStorage`）。

## 🕹 玩法说明

1. **旋转管道**：点击或轻触棋盘中的方块，顺时针旋转 90 度调整管道朝向。
2. **观察链路**：观察左侧火源（🔥）与右侧火箭（🚀）的相对位置，尽量串联更多的火箭。
3. **巧用过桥方块**：遇到横纵交错的线路时，利用立体过桥（Bridge）方块实现双线独立通导，互不干扰。
4. **一火多连策略**：准备就绪后点击底部**“点火”**按钮触发结算。单个火源接通的火箭越多，得分将呈几何级暴击！

---

## 🏆 计分规则

- **连通基础分**：单个火源接通 $N$ 个火箭时，该火源得分公式为：  
  $$\text{Score} = N \times 100 \times N$$  
  *(例如：一火单连得 100 分，一火四连可暴击获得 $4 \times 100 \times 4 = 1600$ 分！)*
- **时间奖励**：过关结算时，剩余秒数将转换为额外奖励分（$\text{剩余秒数} \times \text{当前关卡编号}$）。
- **过关判定**：前 2 关要求达到最低点火命中率，后续高阶关卡要求总分达到门槛。

## 🛠 本地调试与运行

这是一个纯静态项目，可在本地任意 HTTP 服务下启动：

```bash
# 使用 Python 启动本地测试服务器
python3 -m http.server 8080
```
然后在浏览器中打开 `http://localhost:8080` 即可开始游玩。
